## 변경 요약

회원가입 2단계에서 대출 항목이 있을 때 `monthlyPayment`를 필수(0보다 큰 숫자)로 검증하도록 수정했습니다. 빈 값·0이면 다음 단계로 진행할 수 없습니다. 대출 행이 비어 있으면(대출 없음) 해당 검증을 적용하지 않습니다.

## 변경 파일

## 검증 규칙

| 조건 | 동작 |
|------|------|
| 대출 행이 비어 있음 (상품·잔액·월상환 없음) | 검증 생략 |
| 대출 행이 존재 | 상품 선택 + `balance > 0` + `monthlyPayment > 0` 필수 |
| 월 상환액 비어 있음 / 0 / 음수·비숫자 | `"월 상환액을 0보다 큰 금액으로 입력해주세요."` |
