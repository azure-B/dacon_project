# 백엔드 작업 로그 — 2026-09-02

## 요약

Express 백엔드에 로그인 API(`POST /api/auth/login`)를 추가하고, 로컬에서 정상 동작을 확인했다.

## 작업 내용

- 기존 `routes` / `controller` / `models` 패턴에 맞춰 인증 모듈 추가
  - `back/routes/auth.routes.js`
  - `back/controller/auth.controller.js`
  - `back/models/user.model.js`
  - `back/routes/index.js`에 `router.use("/auth", authRoutes)` 연결
- 아이디·비밀번호 검증
  - 필수값 누락 시 `400`
  - 계정 없음/비밀번호 불일치 시 구분 없이 `401` `invalid credentials`
  - 비밀번호는 평문 저장하지 않고 `scrypt` 해시 비교
- 로그인 성공 시 JWT 액세스 토큰 발급 (`tokenType: Bearer`, `expiresIn: 3600`)
- 같은 IP·아이디 기준 15분 내 실패 5회 시 `429` `too many login attempts`
- 요청 필드 `loginId`와 `userId` 모두 수용 (`userId`는 별칭)
- 테스트용 시드 계정: `user01` / `pass1234`

## 확인

- `POST http://localhost:3000/api/auth/login`
- 본문 예시: `{ "userId": "user01", "password": "pass1234" }`
- 결과: `200`, `accessToken` 및 사용자 공개 정보 반환 (비밀번호 미포함)
